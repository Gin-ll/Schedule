# 设计要求：历史回顾行内展开子任务

- 日期：2026-08-19
- 状态：已确认
- 涉及文件：`E:\Schedule\win\src\views\HistoryView.vue`（唯一改动文件）

## 背景

历史回顾页面（`HistoryView.vue`）目前对带子任务的日程只显示一行计数"子任务 X/Y"
（第 83 行），子任务明细不可见，也没有展开交互。需求：**有子任务的日程，点击该行即可展开子任务明细**。

数据层已就绪：`Schedule.subtasks` 为 `{ id, title, completed }[]`，无需数据库或后端改动。

## 范围

- 仅修改 `E:\Schedule\win\src\views\HistoryView.vue`（模板 + script + 局部样式）
- 两个标签页都生效：已完成清单（`completed`）、逾期待整理（`overdue`）
- 无路由、无后端、无数据模型改动

## 交互行为

1. **有子任务**（`s.subtasks?.length > 0`）的日程行：
   - 整行可点击，点击切换展开/收起
   - 标题前显示 chevron 箭头：`lucide:chevron-right`，展开后旋转 90° 变为向下，作为可展开视觉提示
   - 行加 `cursor: pointer` 与 hover 背景提示
2. **无子任务**的日程行：不可点击、无箭头，视觉与现状一致
3. **逾期待整理页**：行内"移至今天 / 删除"按钮点击时阻止冒泡（`@click.stop`），不触发行展开
4. 多行可同时展开，互不影响（各自独立展开状态）

## 展开内容（只读）

- 卡内展开区逐条显示子任务，**仅查看，不可勾选**：
  - 已完成子任务：实心对勾图标（`lucide:check-circle-2`）+ 标题删除线置灰
  - 未完成子任务：空心圆圈图标（`lucide:circle`）+ 正常标题
- 视觉复用现有全局 `.card-subtask-item` 的删除线/置灰风格（`styles.css:633-636`），与主日程页观感一致
- 展开区带轻微上下滑入动画（CSS transition，不引入新依赖）

## 状态实现

- `ref(new Set<string>())` 记录已展开的日程 id
- `toggleExpand(id)` / `isExpanded(id)` 两个函数
- 切换标签页/筛选范围时状态自然保留（条目 id 稳定，无副作用）
